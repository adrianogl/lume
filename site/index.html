Comandos

Uma pílula quando um comando demorado do terminal termina, com o resultado e quanto levou. Enquanto roda, o notch fechado mostra o tempo.

Para quem vive no terminal

O Claude Code avisa. Você não precisa ficar olhando.

  • Várias contas.~/.claude, ~/.claude-trabalho e quantas mais você tiver.
  • A aba certa.Abrir traz para a frente o iTerm da sessão que chamou.
  • Sua status line intacta.O Lume lê o uso e repassa a entrada para o comando que você já tinha.
  • Com backup.Antes de mexer no settings.json, guarda uma cópia. Remover tira só o que é do Lume.

Privacidade

Fica tudo no seu Mac.

Sem conta, sem analytics e sem telemetria. O Lume só vai à rede para baixar o seu link iCal, se você configurar um, e para buscar as pull requests pelo gh que você já tem logado.

Baixar

Três passos e a coruja acorda.

1

Baixe o zip

Lume-0.1.0.zip, na página de releases do GitHub. O SHA-256 vem junto.

2

Mova para Aplicativos

Descompacte e arraste o Lume.app. Ele não tem ícone no Dock: mora no notch.

3

Abra com o botão direito

O release não é notarizado. Botão direito › Abrir. Se o macOS recusar: xattr -dr com.apple.quarantine /Applications/Lume.app
